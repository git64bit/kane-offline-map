Kane Offline Map — Portable Application

This folder is a separate application. It does not replace or modify the original county-field-map folder.

Included:
- browser application files;
- prepared county boundary, roads, water, and buildings;
- portable manifest and integrity hashes;
- writable project-data/sectors location.

Not included:
- data/reviews/current (copied separately after archive extraction);
- TrivialHTTP runtime files (copied separately for each operating system).

The expected browser URL is recorded in START-URL.txt.
